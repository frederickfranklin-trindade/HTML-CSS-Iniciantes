# HTML e CSS para Iniciantes

Repositório educacional com a estrutura de uma primeira página publicada via GitHub Pages — documentado passo a passo para servir de referência a quem está começando em HTML e CSS.

## Sobre o projeto

Este projeto documenta a construção de uma página estática do zero, cobrindo o fluxo completo até a publicação:

- Estruturação de arquivos HTML e CSS
- Controle de versão com Git
- Hospedagem e publicação com GitHub Pages
- Organização de código seguindo boas práticas de mercado

O conteúdo é indicado para quem está dando os primeiros passos em desenvolvimento front-end e quer entender, na prática, como um site simples vai do código ao ar.

## Tecnologias utilizadas

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura da página |
| CSS3 | Estilização e layout |
| Git | Controle de versão |
| GitHub Pages | Hospedagem e publicação |

## Objetivo

Este repositório foi criado para fins educacionais, como parte da minha ampliação de conhecimento técnico em desenvolvimento web. Compartilho o código documentado tanto para consolidar meu próprio aprendizado quanto para apoiar outras pessoas que estão começando na área.

## Como executar localmente

Clone o repositório:

\`\`\`bash
git clone https://github.com/frederickfranklin-trindade/HTML-CSS-Iniciantes.git
\`\`\`

Abra o arquivo \`index.html\` diretamente no navegador — não há dependências ou build necessários.
